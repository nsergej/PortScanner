# Code of Conduct

This project follows a simple rule: be respectful, constructive, and safe.

## Expected Behavior

- Discuss code and ideas professionally.
- Assume good intent when reviewing contributions.
- Keep security discussions responsible and avoid publishing exploit details in
  public issues.
- Respect that this project is a network scanning tool and should be used only
  with authorization.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Encouraging unauthorized scanning or misuse.
- Publishing sensitive vulnerability details before maintainers have a chance to
  respond.

## Enforcement

Maintainers may edit, hide, or remove comments and may close issues or pull
requests that violate this code of conduct.
